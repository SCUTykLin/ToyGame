## 阶段 5 · 地图：解析与渲染

### 5.1 地图文件长什么样

打开 `assets/maps/village.map`：

```
# SIMDRPG map v1
name    village
tileset terrain_summer.png
bg      DemoGame - 2 - Summer.png
size    64 48
weather clear

[GROUND]
17 17 17 17 ...
（64×48 = 3072 个数字）

[SOLID]
0 0 0 0 ...
（同样 3072 个，1 = 挡住）

[ENTITY]
npc_elder 32 20
npc_smith 14 26
portal 62 24 forest 4 24
```

三个细节会咬人：

1. **`bg` 的值含空格**（`DemoGame - 2 - Summer.png`）。
   用 `ss >> bg` 只会读到 `DemoGame`。必须读整行剩余部分。
2. **`GROUND` 和 `SOLID` 的个数必须等于 `w*h`**。
   少一个，后面所有格子的索引全错——症状是地图"斜着错位"。
   加载时必须校验，宁可 abort。
3. **`tileset` 可能在两个目录**。`rift.map` 用的是 `0-tileset-32x32.png`，
   它在 `backgrounds/` 而不是 `terrain/`。先查 `terrain/`，找不到再查 `backgrounds/`。

### 5.3 `include/world/TileMap.h`

<!-- FILE: include/world/TileMap.h -->
```cpp
#pragma once
#include "gfx/Surface.h"
#include "core/Types.h"

#include <string>
#include <vector>

namespace world {

using core::Rect;
using core::Pixel;

// 地图里 [ENTITY] 段的一行
struct EntitySpawn {
    std::string type;         // enemy_bandit / npc_elder / portal / boss_trex
    int x = 0, y = 0;         // 格子坐标（不是像素）

    // 只有 portal 用得上
    std::string target_map;
    int tx = 0, ty = 0;
};

class TileMap {
public:
    static constexpr int TS = 32;      // tile 边长（像素）

    std::string name, tileset, bg, weather;

    int w = 0, h = 0;                  // 以 tile 为单位
    int tpr = 16;                      // tiles per row：图集每行几个 tile

    std::vector<int>     ground;       // 每格的地形索引
    std::vector<uint8_t> solid;        // 1 = 挡住
    std::vector<uint8_t> decor;        // 每格的装饰物索引（0 = 空，i = PROPS[i-1]）
    std::vector<EntitySpawn> spawns;

    gfx::Surface image;                // 图集

    TileMap() = default;

    // image 是 Surface（禁拷贝），所以隐式移动会被抑制，必须显式声明。
    // 报错是 C2280「尝试引用已删除的函数」，看不出跟 Surface 有关。
    TileMap(const TileMap&) = delete;
    TileMap& operator=(const TileMap&) = delete;
    TileMap(TileMap&&) noexcept = default;
    TileMap& operator=(TileMap&&) noexcept = default;

    static TileMap load(const std::string& path);

    // ---------------------------------------------------------------
    // 编辑器接口
    //
    // 这四个函数是**纯逻辑**：不碰 SDL、不碰鼠标、不碰渲染。
    // 所以它们能被脚本驱动做回归测试（tests/edit_test.cpp），
    // GUI 只是套在外面的一层壳。
    //
    // 全部做越界保护 —— 鼠标拖到窗口外面是常态，不能崩。
    // ---------------------------------------------------------------
    void paint(int x, int y, int index) {
        if (x < 0 || y < 0 || x >= w || y >= h) return;
        ground[size_t(y) * size_t(w) + size_t(x)] = index;
    }

    void set_solid(int x, int y, bool s) {
        if (x < 0 || y < 0 || x >= w || y >= h) return;
        solid[size_t(y) * size_t(w) + size_t(x)] = s ? 1 : 0;
    }

    void toggle_solid(int x, int y) {
        if (x < 0 || y < 0 || x >= w || y >= h) return;
        uint8_t& v = solid[size_t(y) * size_t(w) + size_t(x)];
        v = v ? 0 : 1;
    }

    // 填一片装饰物（编辑器里选区填充用）
    void fill_decor(int x0, int y0, int x1, int y1, int idx) {
        if (x0 > x1) { const int t = x0; x0 = x1; x1 = t; }
        if (y0 > y1) { const int t = y0; y0 = y1; y1 = t; }
        for (int y = y0; y <= y1; ++y)
            for (int x = x0; x <= x1; ++x)
                paint_decor(x, y, idx);
    }

    // 矩形填充（从按下拖到抬起，两角之间全填）
    void fill(int x0, int y0, int x1, int y1, int index);

    // 存回 .map。写出来的格式和 load 读的格式**完全对称**——
    // 保存后重新 load 必须得到一模一样的地图（edit_test 会验证这点）。
    bool save(const std::string& path) const;

    // 换图集（编辑器里按 Tab 在四季之间循环）。
    // 先找 terrain/，再找 backgrounds/；都找不到返回 false 且不动现有图。
    bool set_tileset(const std::string& file);

    // 图集里一共有几个 tile —— 用来 clamp 画笔索引，防止画到越界
    int tile_count() const {
        const int rows = (image.height() > 0) ? image.height() / TS : 0;
        return tpr * rows;
    }

    int at(int x, int y) const {
        return ground[size_t(y) * size_t(w) + size_t(x)];
    }

    // 装饰物索引。0 = 空格子。
    // 装饰层可能是空的（老地图没 [DECOR] 段），所以要先判空。
    int decor_at(int x, int y) const {
        if (decor.empty()) return 0;
        if (x < 0 || y < 0 || x >= w || y >= h) return 0;
        return decor[size_t(y) * size_t(w) + size_t(x)];
    }

    void paint_decor(int x, int y, int idx) {
        if (decor.empty()) return;
        if (x < 0 || y < 0 || x >= w || y >= h) return;
        decor[size_t(y) * size_t(w) + size_t(x)] = uint8_t(idx);
    }

    bool is_solid(int x, int y) const {
        if (x < 0 || y < 0 || x >= w || y >= h) return true;   // 地图外一律当墙
        return solid[size_t(y) * size_t(w) + size_t(x)] != 0;
    }

    Rect tile_rect(int index) const {
        return { (index % tpr) * TS, (index / tpr) * TS, TS, TS };
    }

    int pixel_width()  const { return w * TS; }
    int pixel_height() const { return h * TS; }
};

} // namespace world
```

**`is_solid` 越界返回 `true`** 是一个刻意的决定。
不这么做的话，角色走到地图边缘会掉出去——因为 `solid[]` 里没数据，
读到的可能是 0，于是"地图外面是空的"，角色一路走出世界。

### 5.4 `src/world/TileMap.cpp`

<!-- FILE: src/world/TileMap.cpp -->
```cpp
#include "world/TileMap.h"
#include "gfx/Atlas.h"

#include <cstdio>
#include <cstdlib>
#include <filesystem>
#include <fstream>
#include <sstream>
#include <system_error>   // std::error_code

namespace world {

namespace fs = std::filesystem;

// 去掉行尾的 \r（Windows 换行）。不做的话 bg 那行最后会多一个 \r，
// 导致文件名对不上，报"文件不存在"但看起来完全一样。
static void strip_cr(std::string& s) {
    while (!s.empty() && (s.back() == '\r' || s.back() == '\n')) s.pop_back();
}

TileMap TileMap::load(const std::string& path) {
    std::ifstream in(path);
    if (!in) {
        std::fprintf(stderr, "打不开地图: %s\n", path.c_str());
        std::abort();
    }

    TileMap m;

    enum class Sec { Header, Ground, Solid, Decor, Entity };
    Sec sec = Sec::Header;

    std::string line;
    while (std::getline(in, line)) {
        strip_cr(line);
        if (line.empty()) continue;
        if (line[0] == '#') continue;

        // 段标记
        if (line[0] == '[') {
            if (line == "[GROUND]") sec = Sec::Ground;
            else if (line == "[SOLID]") sec = Sec::Solid;
            else if (line == "[DECOR]") sec = Sec::Decor;
            else if (line == "[ENTITY]") sec = Sec::Entity;
            continue;
        }

        if (sec == Sec::Header) {
            std::istringstream ss(line);
            std::string key;
            ss >> key;

            if (key == "name")         { ss >> m.name; }
            else if (key == "tileset") { ss >> m.tileset; }
            else if (key == "weather") { ss >> m.weather; }
            else if (key == "size")    { ss >> m.w >> m.h; }
            else if (key == "bg") {
                // bg 的值可能含空格（DemoGame - 2 - Summer.png），
                // 不能用 ss >> bg。跳过 key 之后，剩下整行都是值。
                std::string rest;
                std::getline(ss, rest);
                const size_t p = rest.find_first_not_of(" \t");
                m.bg = (p == std::string::npos) ? "" : rest.substr(p);
            }
            continue;
        }

        if (sec == Sec::Ground) {
            std::istringstream ss(line);
            int v;
            while (ss >> v) m.ground.push_back(v);
            continue;
        }

        if (sec == Sec::Solid) {
            std::istringstream ss(line);
            int v;
            while (ss >> v) m.solid.push_back(uint8_t(v));
            continue;
        }

        if (sec == Sec::Decor) {
            std::istringstream ss(line);
            int v;
            while (ss >> v) m.decor.push_back(uint8_t(v));
            continue;
        }

        // Entity
        {
            std::istringstream ss(line);
            EntitySpawn e;
            ss >> e.type >> e.x >> e.y;
            if (e.type == "portal") ss >> e.target_map >> e.tx >> e.ty;
            m.spawns.push_back(e);
        }
    }

    // 校验：数据量必须刚好等于 w*h
    const size_t need = size_t(m.w) * size_t(m.h);
    if (need == 0 || m.ground.size() != need || m.solid.size() != need) {
        std::fprintf(stderr,
            "地图数据不完整: %s\n  期望 %zu 格, ground=%zu solid=%zu\n",
            path.c_str(), need, m.ground.size(), m.solid.size());
        std::abort();
    }

    // 装饰层是后加的，老地图没有这一段 —— 补成空，不算错误。
    // 但如果有，就必须正好是 w*h，否则是导出漏了数据。
    if (!m.decor.empty() && m.decor.size() != need) {
        std::fprintf(stderr,
            "装饰层格数不对: %s\n  期望 %zu 格, decor=%zu\n",
            path.c_str(), need, m.decor.size());
        std::abort();
    }
    if (m.decor.empty()) m.decor.assign(need, 0);

    // 图集：先 terrain/，再 backgrounds/
    std::error_code ec;
    fs::path p = fs::path("assets/gfx/terrain") / m.tileset;
    if (!fs::exists(p, ec)) p = fs::path("assets/gfx/backgrounds") / m.tileset;
    if (!fs::exists(p, ec)) {
        std::fprintf(stderr, "找不到图集: %s\n", m.tileset.c_str());
        std::abort();
    }

    m.image = gfx::load_png(p.string());
    m.tpr = m.image.width() / TS;
    if (m.tpr <= 0) {
        std::fprintf(stderr, "图集宽度不是 %d 的倍数: %s\n", TS, m.tileset.c_str());
        std::abort();
    }

    std::printf("[map] %-8s %dx%d  tpr=%d  entities=%zu\n",
                m.name.c_str(), m.w, m.h, m.tpr, m.spawns.size());
    return m;
}

// ---------------------------------------------------------------
void TileMap::fill(int x0, int y0, int x1, int y1, int index) {
    if (x0 > x1) { const int t = x0; x0 = x1; x1 = t; }
    if (y0 > y1) { const int t = y0; y0 = y1; y1 = t; }
    for (int y = y0; y <= y1; ++y)
        for (int x = x0; x <= x1; ++x)
            paint(x, y, index);
}

bool TileMap::save(const std::string& path) const {
    std::ofstream out(path);
    if (!out) {
        std::fprintf(stderr, "写地图失败（打不开）: %s\n", path.c_str());
        return false;
    }

    // 头部的顺序和格式要和 load 一致，否则来回存读会漂移
    out << "# SIMDRPG map v1\n";
    out << "name    " << name    << '\n';
    out << "tileset " << tileset << '\n';
    out << "bg      " << bg      << '\n';      // bg 可能为空，留一行空的没事
    out << "weather " << weather << '\n';
    out << "size    " << w << ' ' << h << '\n';

    out << "[GROUND]\n";
    for (int y = 0; y < h; ++y) {
        for (int x = 0; x < w; ++x) {
            if (x) out << ' ';
            out << at(x, y);
        }
        out << '\n';
    }

    out << "[SOLID]\n";
    for (int y = 0; y < h; ++y) {
        for (int x = 0; x < w; ++x) {
            if (x) out << ' ';
            out << int(solid[size_t(y) * size_t(w) + size_t(x)]);
        }
        out << '\n';
    }

    out << "[DECOR]\n";
    for (int y = 0; y < h; ++y) {
        for (int x = 0; x < w; ++x) {
            if (x) out << ' ';
            out << decor_at(x, y);
        }
        out << '\n';
    }

    out << "[ENTITY]\n";
    for (const auto& e : spawns) {
        out << e.type << ' ' << e.x << ' ' << e.y;
        if (e.type == "portal")
            out << ' ' << e.target_map << ' ' << e.tx << ' ' << e.ty;
        out << '\n';
    }

    if (!out) {
        std::fprintf(stderr, "写地图失败（写一半出错）: %s\n", path.c_str());
        return false;
    }
    std::printf("[map] 已保存 %s  (%dx%d, %zu 个实体)\n",
                path.c_str(), w, h, spawns.size());
    return true;
}

bool TileMap::set_tileset(const std::string& file) {
    // 用 error_code 重载：不带它的 exists() 在路径转换失败时**会抛异常**，
    // 而这里调用方（编辑器）不该被一个打错的文件名炸掉。
    // 中文路径尤其容易踩：/utf-8 下窄字符串是 UTF-8，filesystem 却按 GBK 解释。
    std::error_code ec;

    fs::path p = fs::path("assets/gfx/terrain") / file;
    if (!fs::exists(p, ec)) p = fs::path("assets/gfx/backgrounds") / file;
    if (!fs::exists(p, ec)) {
        std::fprintf(stderr, "换图集失败，找不到: %s\n", file.c_str());
        return false;
    }

    gfx::Surface img = gfx::load_png(p.string());
    const int cols = img.width() / TS;
    if (cols <= 0) {
        std::fprintf(stderr, "图集宽度不对: %s\n", file.c_str());
        return false;
    }

    image   = std::move(img);
    tpr     = cols;
    tileset = file;
    return true;
}

} // namespace world
```

**为什么 `tpr` 要算出来，不能写死 16**：
`terrain_*.png` 是 512 宽 = 16 列，但 `rift` 用的 ninja 图集列数不同。
写死 16 的话，`tile_rect` 算出来的源矩形会整片错位，画面变成一堆碎片。

### 5.6 装饰物：`include/world/Props.h`

光有地形层，地图能跑但**不好看**：一片草地加几条土路，看不出这是村庄还是森林。

让它像样的东西是**装饰物**：树、木桶、墓碑、篝火、路牌。
它们和 tile 的区别：

| | tile | prop |
|---|------|------|
| 尺寸 | 固定 32×32 | 任意，比如一棵 146×187 的树 |
| 铺法 | 铺满整格 | 底部中点对齐格子底部，往上溢 |
| 数量 | 每格一个 | 稀疏，大部分格子是空的 |

> ⚠ **这一节的代码是阶段 24 改造后的版本**：道具不再自带像素，
> 而是引用 `AssetBank` 里的下标，还能从 `props.cfg` 读自定义道具。
> 它依赖 `include/world/AssetBank.h`，所以按顺序学的读者请先花十分钟
> 把 `03g` 24.6 的 `AssetBank` 建出来（两个文件，只依赖 Surface/Atlas），
> 再回来抄这一节。只剩 `Props.cpp` 里那张 33 行的 `kProps[]` 表没变。

<!-- FILE: include/world/Props.h -->
```cpp
#pragma once
#include "gfx/Surface.h"

#include <string>
#include <vector>

namespace world {

class AssetBank;
class TileMap;

// 一条装饰物的定义。只写"从哪张图的哪块"，尺寸和对齐在加载时算。
struct PropDef {
    const char* file;      // 相对 assets/gfx
    int  sx, sy, sw, sh;   // 源矩形；sw == 0 表示用整张图
    bool solid;            // 落笔时是否顺手把格子设成碰撞
    bool tall;             // true = 和实体一起按 y 排序（能挡住人）
                           // false = 贴地画（永远垫在最下面）
    bool interactive = false;   // 能不能按 E
};

// ---------------------------------------------------------------
// 可交互道具的编号（地图 [DECOR] 里存的值，1-based）
//
// ⚠ 这些必须和 Props.cpp 里 kProps[] 的顺序严格对应。
// 改表的时候顺手改这里，否则"按 E 开宝箱"会开成墓碑。
// ---------------------------------------------------------------
namespace prop_id {
    constexpr int Jar1  = 16;
    constexpr int Jar2  = 17;
    constexpr int Chest = 22;
    constexpr int Sign1 = 23;
    constexpr int Sign2 = 24;
    constexpr int Fire  = 25;
}

// ---------------------------------------------------------------
// 一张"道具表"：33 个内置 + 资产编辑器注册的自定义道具
//
// 关键设计：**道具不自己存像素**，只存 AssetBank 的下标。
// 这样 AssetBank 热重载一张树，地图上所有树下一帧就变了，
// 不需要通知任何人，也不需要重建任何东西。
//
// 地图里的 decor 是 uint8_t，所以道具编号只能是 1..255，
// 而且必须**连续**（id == 下标 + 1）—— 中间断一个，
// 后面所有道具的编号都会错位，整张地图的装饰物集体变成别的东西。
// ---------------------------------------------------------------
class PropSet {
public:
    // manifest 存自定义道具（编辑器保存的那部分）。文件不存在就只用内置表。
    bool load(AssetBank& bank, const std::string& manifest = "assets/props.cfg");

    // AssetBank 重扫之后下标会变，必须调一次把 rel 重新映射成 index。
    void reindex(AssetBank& bank);

    // 把某个素材注册成道具，返回 1-based id；表满（255）返回 0。
    // rel 已经在表里就直接返回原来的 id。
    int  add(const std::string& rel, bool solid, bool tall, bool interactive);

    // rel 对应的 id，0 = 没注册过
    int  id_of(const std::string& rel) const;

    int count() const { return int(items_.size()); }

    const gfx::Surface& image(int i);
    const std::string& rel(int i) const { return items_[size_t(i)].rel; }
    std::string  label(int i) const;          // 去掉目录和扩展名，给 UI 用

    int  sx(int i) const { return items_[size_t(i)].sx; }
    int  sy(int i) const { return items_[size_t(i)].sy; }
    int  sw(int i) const { return items_[size_t(i)].sw; }
    int  sh(int i) const { return items_[size_t(i)].sh; }
    int  dw(int i) const { return items_[size_t(i)].dw; }   // 落笔后的显示尺寸
    int  dh(int i) const { return items_[size_t(i)].dh; }
    int  ax(int i) const { return items_[size_t(i)].ax; }
    int  ay(int i) const { return items_[size_t(i)].ay; }

    bool solid(int i) const       { return items_[size_t(i)].solid; }
    bool tall(int i) const        { return items_[size_t(i)].tall; }
    bool interactive(int i) const { return items_[size_t(i)].interactive; }
    bool custom(int i) const      { return items_[size_t(i)].custom; }
    bool valid(int i) const       { return i >= 0 && i < count(); }

    // ---- 资产编辑器改属性 ----
    void set_flags(int i, bool solid, bool tall, bool interactive);
    void set_scale(int i, int percent);          // 10..400
    void set_offset(int i, int ox, int oy);      // 像素

    int scale(int i) const  { return items_[size_t(i)].scale; }
    int ox(int i) const     { return items_[size_t(i)].ox; }
    int oy(int i) const     { return items_[size_t(i)].oy; }

    // 只把 custom == true 的写出去（内置表在代码里，不需要存）
    bool save_manifest(const std::string& path) const;
    const std::string& manifest_path() const { return manifest_path_; }

private:
    struct Item {
        std::string rel;
        int  asset = -1;       // AssetBank 下标；-1 = 图不在
        int  sx = 0, sy = 0, sw = 0, sh = 0;
        int  dw = 0, dh = 0;   // 按 scale 算出来的显示尺寸
        int  ax = 0, ay = 0;   // 绘制偏移（底部中点对齐 + ox/oy）
        int  scale = 100;
        int  ox = 0, oy = 0;
        bool solid = false, tall = true, interactive = false;
        bool custom = false;
    };

    void recalc(int i);
    void load_manifest(const std::string& path);
    void append(const std::string& rel, int sx, int sy, int sw, int sh,
                bool solid, bool tall, bool interactive, bool custom);

    AssetBank* bank_ = nullptr;
    std::vector<Item> items_;
    std::string manifest_path_;
```

```cpp
void PropSet::recalc(int i) {
    Item& it = items_[size_t(i)];

    // 源尺寸默认"整张图"。第一次算的时候才去解码。
    if (it.sw <= 0 || it.sh <= 0) {
        if (it.asset >= 0) {
            const gfx::Surface& img = bank_->image(it.asset);
            it.sw = std::max(1, img.width());
            it.sh = std::max(1, img.height());
        } else {
            it.sw = 32;                      // 图不在：占位 1 格
            it.sh = 32;
        }
        if (it.sx > it.sw) it.sx = 0;
        if (it.sy > it.sh) it.sy = 0;
    }

    it.dw = std::max(1, it.sw * it.scale / 100);
    it.dh = std::max(1, it.sh * it.scale / 100);

    // 底部中点对齐格子底部中点：
    // 一个 146×187 的树，ax = (32-146)/2 = -57，ay = 32-187 = -155，
    // 于是它从当前格子向上长 5 格。
    it.ax = (TileMap::TS - it.dw) / 2 + it.ox;
    it.ay = TileMap::TS - it.dh + it.oy;
}

                     bool solid, bool tall, bool interactive, bool custom) {

}

void PropSet::load_manifest(const std::string& path) {
    std::ifstream in(path);
    if (!in) {
        std::printf("[props] 没有 %s，只用内置表\n", path.c_str());
        return;
    }

    std::string line;
    int added = 0, fixed = 0, dropped = 0;
    while (std::getline(in, line)) {
        if (!line.empty() && line.back() == '\r') line.pop_back();
        if (line.empty() || line[0] == '#') continue;

        std::istringstream ss(line);
        int  id   = 0;
        std::string rel;
        int  solid = 0, tall = 1, inter = 0;
        int  sx = 0, sy = 0, sw = 0, sh = 0, scale = 100, ox = 0, oy = 0;
        if (!(ss >> id >> rel)) continue;
        ss >> solid >> tall >> inter >> sx >> sy >> sw >> sh >> scale >> ox >> oy;

        if (id <= 0 || id > kMaxProps) { ++dropped; continue; }

        // id 必须连续。中间断了就补占位道具，否则后面全体错位。
        while (int(items_.size()) + 1 < id) {
            append("?", 0, 0, 0, 0, false, false, false, true);
            ++fixed;
            std::fprintf(stderr, "[props] id %d 前有空位，补一个占位道具\n",
                         int(items_.size()));
        }
        if (int(items_.size()) + 1 != id) { ++dropped; continue; }   // 重复 id

        append(rel, sx, sy, sw, sh, solid != 0, tall != 0, inter != 0, true);

        Item& it = items_.back();
        it.scale = std::clamp(scale, 10, 400);
        it.ox = ox;
        it.oy = oy;
        recalc(int(items_.size()) - 1);
        ++added;
    }

    std::printf("[props] %s：自定义 %d 个，补位 %d 个，丢弃 %d 个\n",
                path.c_str(), added, fixed, dropped);
}

bool PropSet::load(AssetBank& bank, const std::string& manifest) {
    bank_ = &bank;
    manifest_path_ = manifest;

    items_.clear();
    items_.reserve(size_t(kPropCount) + 32);

    for (int i = 0; i < kPropCount; ++i) {
        const PropDef& d = kProps[i];
        append(d.file, d.sx, d.sy, d.sw, d.sh, d.solid, d.tall, d.interactive, false);
    }

    load_manifest(manifest);

    std::printf("[props] 载入 %d 个装饰物（内置 %d + 自定义 %d）\n",
                count(), kPropCount, count() - kPropCount);
    return true;
}

}
```

### 5.5 渲染：只画可见的格子

64×48 = 3072 个 tile，全画是 3072 次 `blit_opaque`。

```cpp
// 放在 Game::draw_world()
void Game::draw_world() {
    const int ts = world::TileMap::TS;
    const int cx = cam_.render_x();
    const int cy = cam_.render_y();

    // 可见格子范围（多算 1 格，防止边缘露白）
    const int x0 = cx / ts;
    const int y0 = cy / ts;
    const int x1 = (cx + fb_.width())  / ts + 1;
    const int y1 = (cy + fb_.height()) / ts + 1;

    for (int ty = y0; ty <= y1 && ty < map_.h; ++ty) {
        if (ty < 0) continue;
        for (int tx = x0; tx <= x1 && tx < map_.w; ++tx) {
            if (tx < 0) continue;
            const int idx = map_.at(tx, ty);
            gfx::blit_opaque(fb_, map_.image, map_.tile_rect(idx),
                             tx * ts - cx, ty * ts - cy);
        }
    }
}
```

**`tx < 0` 和 `tx >= w` 两个都要防**。
`blit_opaque` 里有裁剪不会崩，但 `map_.at()` 会越界读到别的行——
画面会出现随机的错乱 tile。

## 阶段 6 · 相机

### 6.1 相机就是一次平移

世界坐标 → 屏幕坐标：

```
screen_x = world_x - cam.x
screen_y = world_y - cam.y
```

`cam.x` 是"屏幕左上角对应世界的哪个像素"。相机跟着玩家时：

```
cam.x = player.x - screen_w / 2
```

然后**夹住**，不让它超出地图：

```
cam.x = clamp(cam.x, 0, map_w_px - screen_w)
```

不夹的话，走到地图边缘会看到黑边。

### 6.2 `include/world/Camera.h`

<!-- FILE: include/world/Camera.h -->
```cpp
#pragma once
#include <algorithm>
#include <cstdlib>

namespace world {

struct Camera {
    int x = 0, y = 0;              // 屏幕左上角对应的世界坐标

    // 震屏
    float shake_time = 0.f;
    float shake_mag  = 0.f;

    void follow(int target_x, int target_y, int view_w, int view_h,
                int map_w_px, int map_h_px) {
        x = target_x - view_w / 2;
        y = target_y - view_h / 2;

        const int max_x = std::max(0, map_w_px - view_w);
        const int max_y = std::max(0, map_h_px - view_h);
        x = std::clamp(x, 0, max_x);
        y = std::clamp(y, 0, max_y);
    }

    void shake(float mag, float duration) {
        shake_mag  = mag;
        shake_time = duration;
    }

    void update(float dt) {
        if (shake_time <= 0.f) return;
        shake_time -= dt;
        if (shake_time <= 0.f) {
            shake_time = 0.f;
            shake_mag  = 0.f;
        }
    }

    // 绘制时用这两个，不要直接用 x / y
    int render_x() const { return shake_time > 0.f ? x + offset() : x; }
    int render_y() const { return shake_time > 0.f ? y + offset() : y; }

private:
    // 最后 0.1 秒逐渐减弱，不然震屏会"啪"地停住，很生硬
    int offset() const {
        const float k = shake_time > 0.1f ? 1.f : shake_time * 10.f;
        const int amp = int(shake_mag * k);
        if (amp <= 0) return 0;
        return (std::rand() % (amp * 2 + 1)) - amp;
    }
};

} // namespace world
```

**为什么 `x` 和 `render_x()` 要分开**：
`x` 是"稳定"的相机位置，逻辑代码（判断某个东西是否在屏幕内）应该用它。
`render_x()` 加了随机抖动，只在绘制时用。
直接改 `x` 的话，抖动会累积，画面会漂走。

**同一帧只能取一次**。`render()` 开头取一次 `cx/cy` 存起来，
之后所有绘制都用这两个值。每个实体各调一次 `render_x()` 的话，
它们抖的方向都不一样，画面会碎。

## 阶段 7 · 角色动画

### 7.1 规格必须记牢

LPC 角色图集（`chars/hero_walk.png`）是 **512×256**：

```
        帧0   帧1   帧2   帧3   帧4   帧5   帧6   帧7
行0(背)  ...
行1(左)  ...
行2(正)  ...
行3(右)  ...
```

- 每帧 **64×64**
- 8 列 × 4 行
- **行序是 背 / 左 / 正 / 右**，不是 上 / 下 / 左 / 右！

这个顺序是 LPC 的约定，写错了角色会"倒着走"（按上却朝下）。
判断方法：`row = 0` 时看不到脸，`row = 2` 时能看到脸。

### 7.2 `include/game/Animator.h`

<!-- FILE: include/game/Animator.h -->
```cpp
#pragma once
#include "gfx/Surface.h"
#include "core/Types.h"

namespace game {

// 只管"现在该取哪一帧"，不管绘制。
struct Animator {
    const gfx::Surface* sheet = nullptr;

    int fw = 64, fh = 64;      // 单帧尺寸
    int frames = 8;            // 每行几帧
    int rows = 4;              // 图集有几行（LPC 角色 4 行，怪物 1 行）

    float fps = 8.f;
    int col = 0;
    int row = 2;               // 默认朝下（正面）
    float timer = 0.f;

    void setup(const gfx::Surface* s, int w, int h, int n, int r) {
        sheet = s; fw = w; fh = h; frames = n; rows = r;
        col = 0; row = (r >= 4) ? 2 : 0;
        timer = 0.f;
    }

    void update(float dt, bool moving, int dx, int dy) {
        // 只有 4 行图集才有方向；怪物图集 1 行，永远 row=0
        if (rows >= 4 && moving) {
            if      (dy < 0) row = 0;   // 上 → 背
            else if (dy > 0) row = 2;   // 下 → 正
            else if (dx < 0) row = 1;   // 左
            else if (dx > 0) row = 3;   // 右
        }

        // 4 行角色：站着不动就停在第一帧
        // 1 行怪物：一直动，否则看起来像贴图
        const bool animate = moving || rows < 4;

        if (!animate) {
            col = 0;
            timer = 0.f;
            return;
        }

        timer += dt;
        const float step = 1.f / fps;
        while (timer >= step) {
            timer -= step;
            col = (col + 1) % frames;
        }
    }

    core::Rect rect() const {
        return { col * fw, row * fh, fw, fh };
    }
};

} // namespace game
```

**`while (timer >= step)` 而不是 `if`**：
如果某一帧卡了 0.5 秒（`dt = 0.5`），`fps = 8`（step = 0.125），
用 `if` 只会前进一帧，动画就"卡住"了；用 `while` 会补上 4 帧。
`timer -= step` 而不是 `timer = 0`，保证长期不漂移。

| `chars/extra/ninja/1.png` | 64×112 | 1 | 单帧 |
| `monsters/tyrannosaurus-1.png` | 906×420 | 6 | 一行 6 帧 |
| `monsters/goblin.png` | 13×10 | 1 | 极小，要放大画 |

所以 `EnemySpec` 里必须有 `fw / fh / frames / draw_w / draw_h` 五个字段，
**不能假设所有人都是 64×64×8**。
`draw_w/draw_h` 是"画到多大"，靠 `blit_stretch` 缩放到统一视觉尺寸——
不然 13×10 的哥布林和 906×420 的霸王龙放在同一个画面里，比例是崩的。

## 阶段 8 · 碰撞与输入

### 8.1 用什么做碰撞盒

**不要用整张精灵**。64×64 的精灵里，人物实际只占中间一小块，
头顶和脚下大量空白。用整张图做碰撞盒，角色会"隔空撞墙"。

本项目的约定：**碰撞盒 = 脚底一小块**。

```
精灵 64×64，左上角在 (px, py)
碰撞盒 = (px + 16, py + 40, 32, 20)
         ↑ 水平居中    ↑ 靠下（脚）
```

这样角色可以"头和上半身"贴到墙边，视觉上自然。

### 8.2 分轴移动：为什么不能一次移动

假设角色以速度 `(vx, vy)` 斜着走，一次移动到位再检测：
如果撞了，你不知道是 x 方向撞的还是 y 方向撞的，
只能整体取消——角色会"卡住"，贴着墙走不动。

正确做法是**先移动 x 检测，再移动 y 检测**：

```cpp
x += vx;  if (撞墙) x -= vx;      // x 被挡住，但 y 还能走
y += vy;  if (撞墙) y -= vy;
```

效果：贴着墙斜着走时，角色会自然沿墙滑行。

### 8.5 `src/world/Collision.cpp`

<!-- FILE: src/world/Collision.cpp -->
```cpp
#include "world/Collision.h"
#include "world/TileMap.h"

namespace world {

bool box_solid(core::Rect r, const TileMap& m) {
    const int ts = TileMap::TS;

    const int x0 = r.x / ts;
    const int y0 = r.y / ts;

    // 注意 -1：右边界是"最后一个像素的坐标"，不是"右边界外的第一个像素"。
    // 一个 32 宽的盒子放在 x=0，覆盖像素 0..31，只占第 0 格。
    // 写成 (r.x + r.w) / ts 的话会算成第 1 格，角色会"隔一格撞墙"。
    const int x1 = (r.x + r.w - 1) / ts;
    const int y1 = (r.y + r.h - 1) / ts;

    for (int ty = y0; ty <= y1; ++ty)
        for (int tx = x0; tx <= x1; ++tx)
            if (m.is_solid(tx, ty)) return true;

    return false;
}

bool try_move(float& x, float& y, float vx, float vy,
              const TileMap& m, bool flying) {
    bool moved = false;

    if (vx != 0.f) {
        const float nx = x + vx;
        if (flying || !box_solid(feet(nx, y), m)) {
            x = nx;
            moved = true;
        }
    }

    if (vy != 0.f) {
        const float ny = y + vy;
        if (flying || !box_solid(feet(x, ny), m)) {
            y = ny;
            moved = true;
        }
    }

    return moved;
}

} // namespace world
```

**整数除法对负数向零取整**，这是唯一隐患：
`r.x = -1` 时 `-1 / 32 = 0`（不是 -1），左边那格没被检测到。
本项目里角色到不了负坐标（`is_solid` 把地图外当墙），
但以后做"会飞出地图的投射物"时，这里要改成 `floor` 语义。

### 8.6 输入：两种查询，别用错

| 函数 | 含义 | 用在哪 |
|------|------|--------|
| `down(k)` | 这一帧**按着** | 移动（持续） |
| `pressed(k)` | 这一帧**刚按下** | 交互、攻击、切武器（一次性） |

用 `down` 做交互：按一下 E 会触发几十次对话。
用 `pressed` 做移动：按住 D 只走一步。

实现上就是保存上一帧的键盘状态：

```
pressed = 这一帧按着 && 上一帧没按
```

```cpp
// 键盘 + 鼠标。全是 static —— 一个进程只有一个输入设备，
// 传对象到处跑没有意义。
class Input {
public:
    static void begin_frame();     // 循环开头调用
    static void end_frame();       // 循环结尾调用

    static bool down(int scancode);      // 按着
    static bool pressed(int scancode);   // 刚按下（只有这一帧为真）

    // ---------------------------------------------------------------
    // 鼠标
    //
    // 坐标是**窗口**像素，不是内部分辨率。
    // 窗口 1280×720 显示 640×360 的画面，鼠标坐标要除以 2 才能对上格子。

    // ---------------------------------------------------------------
    static int mouse_x();
    static int mouse_y();

    static bool mouse_down(int button);      // 1=左 2=中 3=右
    static bool mouse_pressed(int button);   // 这一帧刚按下
    static bool mouse_released(int button);

    // 本帧滚轮增量：上滚 +1、下滚 -1。end_frame 清零。
    static int wheel();

    // 滚轮没有查询式 API，只能从事件里拿。
    // Window::poll 收到 SDL_MOUSEWHEEL 时调这里累加。
    static void add_wheel(int dy);

private:
    static const unsigned char* curr_;
    static unsigned char prev_[512];

    static int      mx_, my_;
    static uint32_t buttons_, buttons_prev_;
    static int      wheel_;
```

### 8.8 `src/platform/Input.cpp`

<!-- FILE: src/platform/Input.cpp -->
```cpp
#include "platform/Input.h"

#include <SDL.h>
#include <cstring>

namespace platform {

const unsigned char* Input::curr_ = nullptr;
unsigned char Input::prev_[512] = {};

int      Input::mx_ = 0;
int      Input::my_ = 0;
uint32_t Input::buttons_ = 0;
uint32_t Input::buttons_prev_ = 0;
int      Input::wheel_ = 0;

void Input::begin_frame() {
    curr_ = SDL_GetKeyboardState(nullptr);

    // 鼠标位置和按键是查询式的，不用处理事件
    int x = 0, y = 0;
    buttons_ = SDL_GetMouseState(&x, &y);
    mx_ = x;
    my_ = y;

    // wheel_ 故意不在这里清零。
    // 它是在 Window::poll() 里累加的，而 poll() 在 begin_frame() **之前**跑完。
    // 在这里清会把这一帧刚滚的那几下抹掉。
}

void Input::end_frame() {
    if (curr_) std::memcpy(prev_, curr_, SDL_NUM_SCANCODES);
    buttons_prev_ = buttons_;
    wheel_ = 0;                  // 本帧读完了，清掉
}

bool Input::down(int sc) {
    if (!curr_ || sc < 0 || sc >= SDL_NUM_SCANCODES) return false;
    return curr_[sc] != 0;
}

bool Input::pressed(int sc) {
    if (!curr_ || sc < 0 || sc >= SDL_NUM_SCANCODES) return false;
    const bool now = curr_[sc] != 0;
    const bool was = prev_[sc] != 0;
    return now && !was;
}

int Input::mouse_x() { return mx_; }
int Input::mouse_y() { return my_; }

bool Input::mouse_down(int b) {
    if (b < 1 || b > 3) return false;
    return (buttons_ & SDL_BUTTON(b)) != 0;
}

bool Input::mouse_pressed(int b) {
    if (b < 1 || b > 3) return false;
    const uint32_t mask = SDL_BUTTON(b);
    return (buttons_ & mask) != 0 && (buttons_prev_ & mask) == 0;
}

bool Input::mouse_released(int b) {
    if (b < 1 || b > 3) return false;
    const uint32_t mask = SDL_BUTTON(b);
    return (buttons_ & mask) == 0 && (buttons_prev_ & mask) != 0;
}

int  Input::wheel() { return wheel_; }
void Input::add_wheel(int dy) { wheel_ += dy; }

} // namespace platform
```

**调用顺序不能错**：

```
while (poll) {
    Input::begin_frame();     // 1. 读当前键盘
    handle_input();           // 2. 用它
    update(); render();
    Input::end_frame();       // 3. 当前存成"上一帧"
}
```

`end_frame` 放错位置的话 `pressed` 永远是 false
（`prev_` 和 `curr_` 指向同一份数据，永远相等）。

## 阶段 9 · ECS：用配置表管理实体

### 9.1 为什么不用继承

28 种敌人，如果按"能力组合"用继承：

```
Enemy
├── MeleeEnemy
│   ├── ChargingMeleeEnemy
│   └── FlyingMeleeEnemy        ← 飞行 + 冲锋怎么组合？
├── RangedEnemy
│   ├── FlyingRangedEnemy
│   └── SplittingRangedEnemy
...
```

`飞行` 和 `冲锋` 是两个正交的维度，继承树会组合爆炸。
而且"28 种敌人"里大部分差异只是**数值**，不是行为。

ECS 的做法：**能力用位标记，数值用表**。

```cpp
B::Chase | B::Flying | B::Charge
```

加一种敌人 = 加一行表。加一种能力 = 加一个位。

### 9.2 组件和 concept

组件是**纯数据**，没有方法（除了构造）：

```cpp
struct Transform { float x, y; };
struct Health    { int hp, max_hp; };
struct AI        { uint32_t behavior; float speed; };
```

系统是**自由函数**，遍历拥有某组组件的实体：

```cpp
reg.each<Transform, Health, AI>([](Entity e, Transform& t, Health& h, AI& ai) {
    // 只有同时有这三个组件的实体才会进来
});
```

### 9.3 `include/ecs/Registry.h`

<!-- FILE: include/ecs/Registry.h -->
```cpp
#pragma once
#include <bitset>
#include <concepts>
#include <cstddef>
#include <cstdint>
#include <memory>
#include <type_traits>
#include <unordered_map>
#include <utility>
#include <vector>

namespace ecs {

using Entity = uint32_t;

// 无效实体。注意：0 是**合法**实体 id（第一个 create() 就返回 0），
// 所以不能用 0 表示"失败"，否则第一个生成的敌人会被误判。
inline constexpr Entity INVALID_ENTITY = 0xFFFFFFFFu;

// 组件的唯一要求：能默认构造（池子要预分配）
template <typename T>
concept Component = std::is_default_constructible_v<T>;

class Registry {
public:
    static constexpr size_t MAX_COMPONENTS = 32;
    using Mask = std::bitset<MAX_COMPONENTS>;

    Entity create() {
        const Entity e = next_++;
        if (masks_.size() <= e) masks_.resize(size_t(e) + 1);
        return e;
    }

    template <Component T, typename... Args>
    T& add(Entity e, Args&&... args) {
        auto& pool = pool_of<T>();
        if (pool.size() <= e) pool.resize(size_t(e) + 1);
        pool[e] = T{ std::forward<Args>(args)... };
        masks_[e].set(cid<T>());
        return pool[e];
    }

    template <Component T>
    T* get(Entity e) {
        if (e >= masks_.size() || !masks_[e].test(cid<T>())) return nullptr;
        auto& pool = pool_of<T>();
        if (e >= pool.size()) return nullptr;
        return &pool[e];
    }

    template <Component T>
    bool has(Entity e) const {
        return e < masks_.size() && masks_[e].test(cid<T>());
    }

    // 销毁 = 清掉所有组件位。组件内存留着（池化，下次复用）。
    void destroy(Entity e) {
        if (e < masks_.size()) masks_[e].reset();
    }

    void clear() {
        pools_.clear();
        masks_.clear();
        next_ = 0;
    }

    Entity count() const { return next_; }

    // 遍历拥有全部 Ts... 的实体
    template <Component... Ts, typename F>
    void each(F&& f) {
        for (Entity e = 0; e < next_; ++e) {
            if (e >= masks_.size()) break;
            if (masks_[e].none()) continue;          // 已销毁，跳过
            if ((masks_[e].test(cid<Ts>()) && ...)) {
                f(e, *get<Ts>(e)...);
            }
        }
    }

private:
    struct PoolBase { virtual ~PoolBase() = default; };
    template <typename T> struct Pool : PoolBase { std::vector<T> data; };

    template <typename T>
    static size_t cid() {
        static const size_t id = next_id_++;
        return id;
    }

    template <typename T>
    std::vector<T>& pool_of() {
        const size_t id = cid<T>();
        auto it = pools_.find(id);
        if (it == pools_.end()) {
            it = pools_.emplace(id, std::make_unique<Pool<T>>()).first;
        }
        return static_cast<Pool<T>*>(it->second.get())->data;
    }

    inline static size_t next_id_ = 0;

    std::unordered_map<size_t, std::unique_ptr<PoolBase>> pools_;
    std::vector<Mask> masks_;
    Entity next_ = 0;
};

} // namespace ecs
```

**四个设计点**：

1. **`concept Component` 代替基类约束**
   很多人写成 `struct ComponentBase {};` 然后 `static_assert(is_base_of_v<...>)`。
   这会在 MSVC 上报 **C2440：带基类的聚合类型不能用花括号初始化**，
   因为 `T{args...}` 对"有基类的聚合"不合法。
   用 C++20 concept 既避开这个坑，约束也更准确。

2. **`masks_` 是 `vector<bitset<32>>`**
   每个实体一个 32 位掩码。查询 `each<A,B>` 就是两次 `test`。
   比 `set<type_index>` 快一个数量级。

3. **组件池是 `vector<T>`，不是 `map<Entity, T>`**
   按实体 id 直接索引，遍历时内存连续。
   代价是删除后内存不回收，对几百个实体完全无所谓。

4. **`each` 里必须跳过 `masks_[e].none()`**
   不跳的话，被 `destroy` 的实体会带着默认值继续参与遍历——
   症状是"打死的敌人还在，而且满血"。
