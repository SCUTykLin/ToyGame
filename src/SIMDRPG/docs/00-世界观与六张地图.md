# 00 · 世界观与六张地图

> 这一章回答两个问题：**为什么会有太空飞船和恐龙混在一起**，
> 以及**1195 个素材分别用在哪**。

---

## 1. 设定：虚蚀不只腐蚀，它还撕裂

先说清楚一件事：这个项目里会出现中世纪村庄、史前沼泽、太空废墟、
忍者道场和西部荒漠。**这不是偷懒，是设定。**

---

三百年前，世界之树 **Eldra** 用根须织出这片土地。它不说话，只是生长。

三个月前，地底渗出一种灰白色粉末——**虚蚀**（The Blight）。
接触它的草木一天内成灰，动物僵直、温顺、空洞地走动，人则失去语言。

但长老 Maelor 发现了更糟的一件事：

> 虚蚀不是"从地里长出来的"。它是**从外面漏进来的**。
> 它腐蚀到哪里，哪里就变薄——薄到能看见别的世界。
>
> 先是森林里出现了不该存在的骨架，然后是会飞的爬行动物，
> 上个月，村子的北边整块塌了，露出来的是……星星。
> 不是夜空。是**星星本身**，很近，很冷。

于是"时空碎片"（Shard）成了这个世界的新地理。
每一块碎片有自己的物理、自己的怪物、自己的天空。

你（**Aric**，守林人）要做的，是穿过这些碎片，
找到 Eldra 根系的四件圣物，把裂缝缝上。

---

## 2. 为什么这么设计（说给自己听的）

| 你想练的东西 | 这个设定给你的借口 |
|-------------|------------------|
| 6 套完全不同的 tileset | 6 块碎片各有自己的物理法则 |
| 敌人 AI 分 4 类 | 异界生物行为逻辑不同 |
| 5 种天气/后处理 | 碎片的环境参数不同 |
| 武器系统切换（剑/枪） | 从异界捡到的武器 |
| 素材风格不统一 | **这就是卖点，不是 bug** |

## 3. 六张地图

> 下面每一条都和 `assets/maps/*.map` 里的 `[ENTITY]` 段一一对应。
> 改地图就改这三个文件：`tools/gen_maps.py`、`.map`、这一节。

### 3.1 晨曦村（起始）

- **tileset**：`terrain_summer.png` ｜ **天气**：`clear`
- **NPC**：
  - `elder` Maelor（32,20）— 开场剧情，给**森之核**
  - `smith` Brann（14,26）— 给剑（`has_sword`），并把武器换成 `smith_sword`
  - `merchant` Sela（48,34）— 给一瓶药
- **出口**：东（62,24）→ 森林（4,24）
- **门禁**：无（起点）

### 3.2 低语森林

- **tileset**：`terrain_autumn.png` ｜ **天气**：`rain`（2000 条雨线）
- **敌人**：`bandit`×3、`cultist`×2、`knight`×1
- **出口**：西（1,24）→ 村庄（60,24）｜ 东（61,24）→ 山道（4,24）
- **门禁**：进森林需要 `has_sword`（否则提示"得先有把剑"）

### 3.3 霜噬山道

- **tileset**：`terrain_winter.png` ｜ **天气**：`snow`（3000 个白点）
- **敌人**：`cultist`×2、`knight`×2、`bandit`×1
- **出口**：西（2,24）→ 森林（60,24）｜ 东（62,24）→ 地窖（4,24）
- **剧情**：第一次进入时拿到**霜之泪**（`frost_tear`）
- **门禁**：进山道需要 `heartseed`

### 3.4 灰烬地窖

- **tileset**：`terrain_summer.png`（地窖不用雪地图集，靠天气 `none` + 深色调）
- **天气**：`none`
- **NPC**：`elder`（8,22）— 重复对话，交代 Boss
- **敌人**：`cultist`×2、`knight`×2
- **Boss**：`boss_blight`（57,23）→ 掉落**灰烬钥匙**（`ash_key`）
- **出口**：西（2,24）→ 山道（60,24）
- **门禁**：进地窖需要 `frost_tear`

### 3.5 远古兽巢（碎片一）

- **tileset**：`terrain_spring.png` ｜ **天气**：`fog`（整屏叠加）
- **敌人**：`lizard`×2、`insect`×3、`plant`×2、`turtle`×1、
  `mini_tyranno`×2、`ptero`×2（飞行）
- **Boss**：`boss_trex`（55,24）→ 掉落**原始之血**（`primal_blood`）
- **出口**：西（2,24）→ 地窖（60,24）
- **门禁**：进兽巢需要 `ash_key`

### 3.6 星陨裂隙（碎片二 · 终章）

- **tileset**：`0-tileset-32x32.png`（**在 `backgrounds/` 目录**，不是 `terrain/`）
- **天气**：`meteor`（80 颗流星 + 屏幕震动）
- **敌人**：`ship`×4（飞行 + 远程）、`insect`×3
- **Boss**：`boss_dragon`（56,24）→ **结局**
- **出口**：西（2,24）→ 兽巢（60,24）
- **门禁**：进裂隙需要 `primal_blood`

**25 种普通怪 + 3 个 Boss = 28 行。**

> **实现提示**：不要给每种敌人写一个类。用**数据表 + 行为位**：
>
> ```cpp
> namespace B {
>     constexpr uint32_t Chase  = 1u << 0;
>     constexpr uint32_t Ranged = 1u << 1;
>     constexpr uint32_t Flying = 1u << 2;   // 忽略地形碰撞
>     constexpr uint32_t Split  = 1u << 3;   // 死后分裂
>     constexpr uint32_t Summon = 1u << 4;
>     constexpr uint32_t Charge = 1u << 5;
>     constexpr uint32_t Blink  = 1u << 6;
>     constexpr uint32_t Static = 1u << 7;   // 不动
>     constexpr uint32_t Poison = 1u << 8;
>     constexpr uint32_t Shield = 1u << 9;
> }
> ```
>
> 28 种敌人 = 28 行表数据，不是一个 switch。

## 5. 武器

和 `ENEMIES[]` 一样，这张表和 `Combat.h` 的 `WEAPONS[]` 必须一致。

| 名字 | 类型 | 伤害 | 距离 | 冷却 | 弹药 | 穿透 | 怎么拿到 |
|------|------|------|------|------|------|------|----------|
| `rusty_sword` | 近战 | 12 | 28 | 0.35s | ∞ | 否 | 开局自带 |
| `smith_sword` | 近战 | 20 | 36 | 0.32s | ∞ | 否 | 铁匠对话 |
| `flintlock` | 远程 | 35 | 420 | 0.80s | 24 | 否 | 掉落 |
| `laser` | 远程 | 50 | 620 | 0.50s | 12 | **是** | 裂隙 |
| `bone_club` | 近战 | 15 | 32 | 0.45s | ∞ | 否 | 掉落 |

**只有近战有"距离"，远程的 `range` 是子弹速度的一个参考值**——
实际射程由 `Projectile::life × 速度` 决定（1.8s × 420 = 756 像素）。

按 `Q` 切武器。远程武器弹药打光后不能开火（`ammo <= 0` 时直接忽略）。

## 6. 剧情旗标

```cpp
struct QuestFlags {
    bool met_elder, has_sword;
    bool heartseed, frost_tear, ash_key, primal_blood;
    bool boss_defeated;
};
```

| 旗标 | 怎么拿到 | 卡住哪道门 |
|------|----------|------------|
| `has_sword` | 和铁匠 Brann 对话 | 森林 |
| `heartseed` | 和长老 Maelor 对话 | 山道 |
| `frost_tear` | **第一次进入山道** | 地窖 |
| `ash_key` | 击败 `boss_blight`（地窖）| 兽巢 |
| `primal_blood` | 击败 `boss_trex`（兽巢）| 裂隙 |
| `boss_defeated` | 击败任意 Boss | — |

**门禁的代码在 `Quest.h` 的 `can_use_portal`**。
被挡住时 `portal_blocked_reason` 会返回一句具体的话，
不要给玩家一句笼统的"你不能过去"——那等于没做引导。

## 7. 结局

`boss_dragon` 死亡 → `state_ = State::Ending` → 黑屏两行字：

```
ELDRA IS SEALED
BUT THE ROOTS REMEMBER
```

**"封印"不是"胜利"**。Eldra 只是被缝上了，虚蚀还在外面。
这个结尾给续作留了口子，也让"四件圣物"这件事显得像权宜之计而不是魔法解法。
