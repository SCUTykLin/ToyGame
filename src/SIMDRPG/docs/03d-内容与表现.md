### 12.2 对话数据：先用代码表，别上 JSON


三条理由：

1. 编译期检查。打错字是编译错误，不是运行时黑屏。

等你的对话超过 200 条，再考虑外部文件。

```cpp
#pragma once
#include <cstring>
#include <string>
#include <vector>

namespace game {

struct Line {
    const char* who;        // 说话人
    const char* text;       // 内容
    const char* faceset;    // 头像（可空）
};

struct DialogState {
    const std::vector<Line>* lines = nullptr;
    int   index = 0;
    float chars_shown = 0.f;
    float speed = 40.f;      // 每秒显示多少字
    bool  active = false;

    void start(const std::vector<Line>& l) {
        lines = &l;
        index = 0;
        chars_shown = 0.f;
        active = true;
    }

    const Line& current() const { return (*lines)[size_t(index)]; }

    int text_len() const { return int(std::strlen(current().text)); }

    bool line_done() const { return chars_shown >= float(text_len()); }

    // 返回 true 表示"整段对话结束"
    bool advance() {
        if (!line_done()) {                 // 还没打完：先一次性显示完
            chars_shown = float(text_len());
            return false;
        }
        ++index;
        chars_shown = 0.f;
        if (index >= int(lines->size())) {
            active = false;
            return true;
        }
        return false;
    }

    void update(float dt) {
        if (!active) return;
        chars_shown += speed * dt;
        const float n = float(text_len());
        if (chars_shown > n) chars_shown = n;
    }
};
```

**`advance()` 的两次行为**：
第一次按 E，如果字还没打完，直接显示全部（玩家不想等）；
再按 E 才进入下一句。这是所有文字冒险游戏的标准交互。

**为什么 `lines` 存指针不存值**：
`std::vector<Line>` 拷贝一次要分配内存。
存指针的话，切换对话只是换一个指针。

```cpp
// 门禁：没拿到对应圣物，传送门不工作
inline bool can_use_portal(const world::EntitySpawn& s, const QuestFlags& q) {
    if (s.target_map == "forest" && !q.has_sword)    return false;
    if (s.target_map == "pass"   && !q.heartseed)    return false;
    if (s.target_map == "crypt"  && !q.frost_tear)   return false;
    if (s.target_map == "nest"   && !q.ash_key)      return false;
    if (s.target_map == "rift"   && !q.primal_blood) return false;
    return true;
}

    if (s.target_map == "forest" && !q.has_sword)

    if (s.target_map == "pass" && !q.heartseed)

    if (s.target_map == "crypt" && !q.frost_tear)
        return "地窖的寒气会冻碎骨头。你需要霜之泪。";
    if (s.target_map == "nest" && !q.ash_key)
        return "兽巢的门是烧过的铁。需要灰烬钥匙。";
    if (s.target_map == "rift" && !q.primal_blood)

}
```

### 12.6 交互触发

`check_interactions` 每个 Playing 帧都跑：

```cpp
void Game::check_interactions(float dt) {
    // 1) 传送门冷却（切图后 0.5 秒内不检测，否则会来回弹）
    if (portal_cd_ > 0.f) { portal_cd_ -= dt; return; }

    const int tx = (int(player_.x) + 32) / world::TileMap::TS;
    const int ty = (int(player_.y) + 32) / world::TileMap::TS;

    // 2) 传送门
    for (const auto& s : map_.spawns) {
        if (s.type != "portal") continue;
        if (tx != s.x || ty != s.y) continue;

        if (!can_use_portal(s, quest_)) {
            blocked_hint_ = portal_blocked_reason(s, quest_);
            blocked_t_ = 2.0f;
            continue;
        }
        load_map(s.target_map, s.tx, s.ty);
        return;
    }

    // 3) NPC：按 E，且距离 2 格以内
    if (player_.want_interact) {
        player_.want_interact = false;

        for (const auto& s : map_.spawns) {
            if (s.type.rfind("npc_", 0) != 0) continue;

            const float ddx = float(s.x * world::TileMap::TS) - player_.x;
            const float ddy = float(s.y * world::TileMap::TS) - player_.y;
            if (ddx * ddx + ddy * ddy > 72.f * 72.f) continue;

            const char* kind = s.type.c_str() + 4;

            if (std::strcmp(kind, "elder") == 0) {
                active_lines_ = kElderIntro;
                quest_.met_elder = true;
                quest_.heartseed = true;           // 对话结束就给
            } else if (std::strcmp(kind, "smith") == 0) {
                active_lines_ = kSmithSword;
                quest_.has_sword = true;
                if (inv_.weapon_index == 0) inv_.weapon_index = 1;  // 换成铁匠剑
            } else {
                active_lines_ = kMerchantShop;
            }

            dialog_.start(active_lines_);
            state_ = State::Dialog;
            return;
        }
    }
}
```

**`portal_cd_ = 0.5f` 不能省**。
切图后玩家正站在新地图的传送门上，这一帧立刻又检测到传送门，
于是切回去——两帧之间来回跳，画面疯狂闪烁。
`load_map` 结尾设 `portal_cd_ = 0.5f`，给玩家走出传送门的时间。

## 阶段 13 · 天气（第二个 SIMD 战场）

### 13.1 四种天气

| 天气 | 粒子数 | 行为 |
|------|--------|------|
| `rain` | 2000 | 竖直下落，画成 6 像素竖线 |
| `snow` | 3000 | 带横向漂移，画成 2 像素点 |
| `meteor` | 80 | 斜着高速下落 |
| `fog` | 0 | 不用粒子，整屏叠一层灰 |

`clear` 和 `none` 都是"没有天气"。

### 13.2 数据布局：SoA 不是 AoS

```
AoS（数组的结构）: Particle p[4096];  // 每个 16 字节
    x y vx vy | x y vx vy | ...

SoA（结构的数组）: float x[4096]; float y[4096]; float vx[4096]; float vy[4096];
```

为什么要 SoA：SIMD 一次读 8 个连续 float。
AoS 里 8 个连续的 float 是"两个粒子的全部字段"，你没法只更新 x。
SoA 里 8 个连续 float 就是"8 个粒子的 x"，正好一条 `_mm256_load_ps`。

**这是 SIMD 能不能用的前提条件，不是优化技巧。**

```cpp
namespace world {

// SoA 布局：每个字段一个数组。
// alignas(32) 是给 _mm256_load_ps 用的（它要求 32 字节对齐）。
struct ParticleSystem {
    static constexpr int MAX = 4096;

    alignas(32) float x[MAX]  = {};
    alignas(32) float y[MAX]  = {};
    alignas(32) float vx[MAX] = {};
    alignas(32) float vy[MAX] = {};

    int count = 0;
};

enum class WeatherKind { None, Rain, Snow, Fog, Meteor };

WeatherKind from_string(const char* s);

void reset_rain  (ParticleSystem& p, int count, int w, int h);
void reset_snow  (ParticleSystem& p, int count, int w, int h);
void reset_meteor(ParticleSystem& p, int count, int w, int h);

void update_particles_scalar(ParticleSystem& p, float dt, int screen_h);
void update_particles_simd  (ParticleSystem& p, float dt, int screen_h);

} // namespace world
```

### 13.5 `src/world/Weather.cpp`

<!-- FILE: src/world/Weather.cpp -->
```cpp
#include "world/Weather.h"

#include <cstdlib>
#include <cstring>
#include <immintrin.h>

namespace world {

WeatherKind from_string(const char* s) {
    if (!s) return WeatherKind::None;
    if (std::strcmp(s, "rain")   == 0) return WeatherKind::Rain;
    if (std::strcmp(s, "snow")   == 0) return WeatherKind::Snow;
    if (std::strcmp(s, "fog")    == 0) return WeatherKind::Fog;
    if (std::strcmp(s, "meteor") == 0) return WeatherKind::Meteor;
    return WeatherKind::None;          // "clear" / "none" / 未知
}

static inline int clamp_count(int n) {
    return n < 0 ? 0 : (n > ParticleSystem::MAX ? ParticleSystem::MAX : n);
}

void reset_rain(ParticleSystem& p, int count, int w, int h) {
    p.count = clamp_count(count);
    for (int i = 0; i < p.count; ++i) {
        p.x[i]  = float(std::rand() % (w > 0 ? w : 1));
        p.y[i]  = float(std::rand() % (h > 0 ? h : 1));
        p.vx[i] = 0.f;
        p.vy[i] = 400.f + float(std::rand() % 200);
    }
}

void reset_snow(ParticleSystem& p, int count, int w, int h) {
    p.count = clamp_count(count);
    for (int i = 0; i < p.count; ++i) {
        p.x[i]  = float(std::rand() % (w > 0 ? w : 1));
        p.y[i]  = float(std::rand() % (h > 0 ? h : 1));
        p.vx[i] = -30.f + float(std::rand() % 60);
        p.vy[i] = 40.f + float(std::rand() % 60);
    }
}

void reset_meteor(ParticleSystem& p, int count, int w, int h) {
    p.count = clamp_count(count);
    for (int i = 0; i < p.count; ++i) {
        p.x[i]  = float(std::rand() % (w > 0 ? w * 2 : 1)) - float(w) * 0.5f;
        p.y[i]  = -float(std::rand() % (h > 0 ? h : 1));
        p.vx[i] = 300.f;
        p.vy[i] = 700.f;
    }
}

// ---------------------------------------------------------------
// 标量版：黄金标准
// ---------------------------------------------------------------
void update_particles_scalar(ParticleSystem& p, float dt, int screen_h) {
    const int w = 640;          // 横向回绕边界，和屏幕等宽
    for (int i = 0; i < p.count; ++i) {
        p.x[i] += p.vx[i] * dt;
        p.y[i] += p.vy[i] * dt;

        if (p.y[i] > float(screen_h)) {
            p.y[i] = 0.f;
            p.x[i] = float(std::rand() % w);
        }
        // 横向回绕：出左边从右边进来
        if (p.x[i] < 0.f)    p.x[i] += float(w);
        if (p.x[i] > float(w)) p.x[i] -= float(w);
    }
}

// ---------------------------------------------------------------
// SIMD 版：一次 8 个
// ---------------------------------------------------------------
void update_particles_simd(ParticleSystem& p, float dt, int screen_h) {
    const __m256 dtv = _mm256_set1_ps(dt);
    const __m256 hh  = _mm256_set1_ps(float(screen_h));
    const __m256 zero = _mm256_setzero_ps();
    const __m256 wf  = _mm256_set1_ps(640.f);

    int i = 0;
    for (; i + 8 <= p.count; i += 8) {
        __m256 x  = _mm256_load_ps(p.x  + i);     // 对齐加载，数组是 alignas(32)
        __m256 y  = _mm256_load_ps(p.y  + i);
        const __m256 vx = _mm256_load_ps(p.vx + i);
        const __m256 vy = _mm256_load_ps(p.vy + i);

        x = _mm256_add_ps(x, _mm256_mul_ps(vx, dtv));
        y = _mm256_add_ps(y, _mm256_mul_ps(vy, dtv));

        // y > screen_h → 回到顶部
        const __m256 over = _mm256_cmp_ps(y, hh, _CMP_GT_OQ);
        y = _mm256_blendv_ps(y, zero, over);      // 命中的通道取 0

        // 横向回绕用减法/加法各一次，不需要随机（随机数没法向量化）
        const __m256 lt0 = _mm256_cmp_ps(x, zero, _CMP_LT_OQ);
        x = _mm256_add_ps(x, _mm256_and_ps(lt0, wf));       // x<0 时 +640

        const __m256 gt = _mm256_cmp_ps(x, wf, _CMP_GT_OQ);
        x = _mm256_sub_ps(x, _mm256_and_ps(gt, wf));        // x>640 时 -640

        _mm256_store_ps(p.x + i, x);
        _mm256_store_ps(p.y + i, y);
    }

    // 尾部
    for (; i < p.count; ++i) {
        p.x[i] += p.vx[i] * dt;
        p.y[i] += p.vy[i] * dt;
        if (p.y[i] > float(screen_h)) p.y[i] = 0.f;
        if (p.x[i] < 0.f)       p.x[i] += 640.f;
        if (p.x[i] > 640.f)     p.x[i] -= 640.f;
    }
}

} // namespace world
```

**`_mm256_and_ps(mask, 640.0f)`** 是"条件加法"的常用写法：
`mask` 是全 1 或全 0，与 `640.0f` 与完就是 `640.0f` 或 `0.0f`。
再相加，等于"满足条件才加 640"。

比 `blendv` 快，而且不需要第二个寄存器存"原值"。

**为什么横向回绕不能用 `std::rand()`**：
随机数没法向量化。标量版用一个随机 x 重置雨滴，
SIMD 版改成"回绕"（出左边从右边进）——视觉上看不出区别，
但代码可以向量化。**这是为了 SIMD 改算法的一个真实例子**。

```cpp
void Game::draw_weather() {
    const world::WeatherKind wk = world::from_string(map_.weather.c_str());
    if (wk == world::WeatherKind::None || wk == world::WeatherKind::Fog) return;

    const bool snow = (wk == world::WeatherKind::Snow);
    const core::Pixel color = snow ? 0xE0FFFFFFu : 0xA0B0C8D8u;

    for (int i = 0; i < particles_.count; ++i) {
        const int x = int(particles_.x[i]);
        const int y = int(particles_.y[i]);
        if (x < 0 || x >= fb_.width() || y < 0 || y >= fb_.height()) continue;

        const int len = snow ? 2 : 6;
        for (int k = 0; k < len && y + k < fb_.height(); ++k)
            gfx::blend_pixel_scalar(fb_.row(y + k)[x], color);
    }
}
```

**渲染没有向量化**，因为每个粒子要写的位置是随机的（散点写入），
没法用 SIMD 连续写。**更新可以，渲染不行**——这是粒子系统的常态。

### 13.7 雾和整屏染色

雾不用粒子，直接整屏叠一层半透明灰：

```cpp
const core::Pixel fog = 0x30C0C8D0u;
for (int y = 0; y < fb_.height(); ++y) {
    core::Pixel* r = fb_.row(y);
    for (int x = 0; x < fb_.width(); ++x)
        gfx::blend_pixel_scalar(r[x], fog);
}
```

`0x30` 是 alpha（48/255 ≈ 19%），后面的 `C0C8D0` 是灰蓝色。

**这里不能图省事用 `fill_rect`**：`fill_rect` 是**直接写像素**，不看 alpha。
用它画雾，整屏会被涂成一块纯灰板——我第一次就是这么写的，
截图出来整个兽巢只剩一种颜色。

**这也是一个 SIMD 战场**：`fill_rect` 每帧要写 23 万像素。
但 `fill_rect` 只是写同一个值，编译器会自动向量化，
手写 SIMD 收益不大。真正值得手写的是"整屏 tint"（读+算+写）。

## 阶段 14 · 视差背景

### 14.1 原理

远景比近景动得慢：

```
screen_x = world_x * factor - cam.x * factor
```

`factor = 0.3` 表示"相机走 100 像素，背景走 30 像素"。
这叫视差（parallax），是 2D 游戏制造纵深感最便宜的手段。

### 14.2 实现：平铺

背景图通常比屏幕小（或者只够一张），所以要**平铺**：

```cpp
void Game::draw_parallax() {
    if (map_.bg.empty() || map_.bg == "none") return;
    if (!bg_loaded_) return;

    const float factor = 0.35f;
    const int bw = bg_.width();

    // 背景按 factor 跟随相机，并对 bw 取模，实现无限平铺
    int offset = int(cam_.x * factor) % bw;
    if (offset < 0) offset += bw;

    for (int x = -offset; x < fb_.width(); x += bw) {
        gfx::blit_opaque(fb_, bg_, {0, 0, bw, bg_.height()}, x, 0);
    }
}
```

**`offset < 0` 的处理**：`cam_.x` 不会是负数（相机夹住了），
但 `%` 对负数返回负数，多一层保护不吃亏。

**背景高度可能不够铺满屏幕**（比如 360 高的屏幕配 200 高的背景）。
两个办法：拉伸，或者垂直居中留黑边。本项目直接**从 y=0 开始铺**，
上面的空白由地图自己填——所以背景只在地图上边缘可见时露出来。

### 14.3 六张地图的背景配置

`.map` 里的 `bg` 字段：

| 地图 | bg |
|------|-----|
| village | `DemoGame - 2 - Summer.png` |
| forest | `DemoGame - 3 - Autumn.png` |
| pass | `DemoGame - 4 - Winter.png` |
| crypt / nest / rift | `none`（地窖和异界不需要远景） |

加载时注意：`bg` 在 `backgrounds/` 目录，而且**文件名含空格**。

### 14.4 验收

- [ ] 村庄向右走时，背景移动速度明显慢于地面
- [ ] 走到地图最右边，背景没有露出黑边（平铺生效）
- [ ] 把 `factor` 改成 1.0，背景和地面同速——"纵深感"消失
- [ ] 把 `bg` 改成 `none`，背景消失且不崩

## 阶段 15 · 文字、面板、血条

### 15.1 字体：所有字体图集都是同一布局

`assets/gfx/fonts/` 下有 9 个字体图集，尺寸各异，但**布局完全一致**：

```
120×64      → 15 列 × 8 行，每格 8×8     （font8x8.png）
240×128     → 15 列 × 8 行，每格 16×16   （font-16x16.png）
600×320     → 15 列 × 8 行，每格 40×40   （font-40x40.png）
```

规则：

- **15 列**，不是 16
- 第 0 格是 ASCII 32（空格），依次往后
- 只覆盖 ASCII 32–126（95 个字符），后面是空的

`font8x8.png` 是 120×64，`120/8 = 15` 列，`64/8 = 8` 行。

### 15.4 `src/gfx/Ui.cpp`

<!-- FILE: src/gfx/Ui.cpp -->
```cpp
#include "gfx/Ui.h"
#include "gfx/Blitter.h"

namespace gfx {

int draw_text(Surface& fb, const BitmapFont& f, int x, int y,
              const char* s, Pixel color) {
    if (!f.sheet || !s) return x;

    const int start_x = x;

    for (; *s; ++s) {
        if (*s == '\n') {
            x = start_x;
            y += f.ch;
            continue;
        }

        const int idx = int(static_cast<unsigned char>(*s)) - 32;
        if (idx < 0 || idx >= 95) {     // 非 ASCII（含中文）：留空跳过
            x += f.cw;
            continue;
        }

        const Rect src{ (idx % f.cols) * f.cw,
                        (idx / f.cols) * f.ch,
                        f.cw, f.ch };

        // 用 blit_mask 而不是 blit_tinted：
        // 字形是"形状"，颜色由我们指定。乘法染色对深色字形无效。
        blit_mask(fb, *f.sheet, src, x, y, color);
        x += f.cw;
    }

    return x;
}

void draw_panel(Surface& fb, Rect r, const Surface& sheet, int border) {
    const int sw = sheet.width();
    const int sh = sheet.height();
    const int b  = border;

    if (b <= 0 || sw < 2 * b || sh < 2 * b || r.w < 2 * b || r.h < 2 * b) return;

    // 四角：原样贴，不拉伸（拉伸会让圆角变形）
    blit_opaque(fb, sheet, {0, 0, b, b},                 r.x,             r.y);
    blit_opaque(fb, sheet, {sw - b, 0, b, b},            r.x + r.w - b,   r.y);
    blit_opaque(fb, sheet, {0, sh - b, b, b},            r.x,             r.y + r.h - b);
    blit_opaque(fb, sheet, {sw - b, sh - b, b, b},       r.x + r.w - b,   r.y + r.h - b);

    // 四条边：沿一个方向拉伸
    blit_stretch(fb, sheet, {b, 0, sw - 2 * b, b},
                 {r.x + b, r.y, r.w - 2 * b, b});
    blit_stretch(fb, sheet, {b, sh - b, sw - 2 * b, b},
                 {r.x + b, r.y + r.h - b, r.w - 2 * b, b});
    blit_stretch(fb, sheet, {0, b, b, sh - 2 * b},
                 {r.x, r.y + b, b, r.h - 2 * b});
    blit_stretch(fb, sheet, {sw - b, b, b, sh - 2 * b},
                 {r.x + r.w - b, r.y + b, b, r.h - 2 * b});

    // 中心
    blit_stretch(fb, sheet, {b, b, sw - 2 * b, sh - 2 * b},
                 {r.x + b, r.y + b, r.w - 2 * b, r.h - 2 * b});
}

void draw_bar(Surface& fb, int x, int y, int w, int h, float ratio,
              const Surface& start, const Surface& mid, const Surface& end) {
    if (ratio < 0.f) ratio = 0.f;
    if (ratio > 1.f) ratio = 1.f;

    const int cap_l = start.width();
    const int cap_r = end.width();
    const int fill  = int(float(w - cap_l - cap_r) * ratio);

    blit_opaque(fb, start, {0, 0, cap_l, start.height()}, x, y);
    if (fill > 0) {
        blit_stretch(fb, mid, {0, 0, mid.width(), mid.height()},
                     {x + cap_l, y, fill, h});
    }
    blit_opaque(fb, end, {0, 0, cap_r, end.height()}, x + cap_l + fill, y);
}

void draw_hearts(Surface& fb, int x, int y, int hp, int max_hp,
                 const Surface& full, const Surface& empty) {
    if (max_hp <= 0) return;

    constexpr int PER_HEART = 20;
    const int n = (max_hp + PER_HEART - 1) / PER_HEART;
    const int step = full.width() + 2;

    for (int i = 0; i < n; ++i) {
        const int left = hp - i * PER_HEART;
        const Surface& img = (left >= PER_HEART / 2) ? full : empty;
        blit_alpha(fb, img, {0, 0, img.width(), img.height()},
                   x + i * step, y);
    }
}

} // namespace gfx
```

**九宫格为什么必须"四角原样"**：
如果整张图直接拉伸，圆角会被拉成椭圆。
九宫格把图切成 9 块，四角保持 1:1，只有四条边和中心被拉伸。

**`draw_text` 里 `idx >= 95` 直接跳过**：
ASCII 32+95 = 127，之后是扩展字符。
中文在 UTF-8 里是 3 个字节，每个字节都 >127，会被当作"非 ASCII"逐个跳过，
所以中文**不会显示**，但也不会崩。见 15.6。

### 15.6 中文怎么办

三条路，按成本排序：

| 方案 | 成本 | 效果 |
|------|------|------|
| 全英文 | 0 | 能用，但剧情打折 |
| 用英文点阵字体拼中文 | 高 | 每个汉字要单独画进图集 |
| 引入 SDL_ttf + 中文字体 | 中 | 一次搞定，但要改渲染管线 |

**建议先全英文跑通整个游戏**，最后再考虑中文。
不要在"字还没出来"的时候去啃字体渲染——那会让你分不清是哪个环节错了。

本项目 `Dialog.h` 里的对话是中文，跑起来会显示成空白。
想立刻看到中文效果，把对话改成英文，或者接 SDL_ttf。
**这是一个已知的、有意的取舍**，不是 bug。

### 15.7 血条：为什么是三段式

`ui/bar-start.png`（3×18）+ `ui/bar-middle.png`（可拉伸）+ `ui/bar-end.png`。
只拉伸中间段，两端的圆头不会变形。

```cpp
// 血量 60/100，宽 200
gfx::draw_bar(fb_, 8, 8, 200, 18, float(player_.hp) / player_.max_hp,
              tex_bar_start_, tex_bar_mid_, tex_bar_end_);
```

`ratio` 必须夹在 [0,1]。不夹的话 `hp = -50` 会算出负宽度，
`blit_stretch` 遇到 `d.w <= 0` 会直接 return，看起来"血条消失"——
虽然不崩，但界面上少了东西，很难查。

## 阶段 16 · Boss 与结局

### 16.1 三阶段：改参数，不换贴图

Boss 的三个阶段只是数值变化：

| 阶段 | 触发 | 变化 |
|------|------|------|
| 1 | 100%–66% | 原始数值 |
| 2 | 66%–33% | 速度 ×1.3，攻击冷却 ×0.7 |
| 3 | 33%–0% | 速度 ×1.6，攻击冷却 ×0.5，震屏 |

不换贴图，因为素材只有一张。要换的话在 `EnemySpec` 里加 `sprite_p2`，
在阶段切换时换 `Sprite::sheet`。

### 16.2 阶段转换

Boss 阶段不单独写函数，直接放在 `update_enemies` 的 lambda 里
（和 03e 的完整 `Game.cpp` 一致）：

```cpp
// update_enemies 的 lambda 内，处理完死亡之后
if (Boss* b = reg_.get<Boss>(e)) {
    const float ratio = float(h.hp) / float(h.max_hp);
    const int want = (ratio > 0.66f) ? 1 : (ratio > 0.33f ? 2 : 3);

    if (want != b->phase) {
        b->phase = want;
        cam_.shake(7.f, 0.45f);          // 切阶段震一下，给玩家反馈
        std::printf("[boss] 进入第 %d 阶段\n", want);
    }

    const float k = (b->phase == 1) ? 1.f : (b->phase == 2 ? 1.3f : 1.6f);
    ai.speed = 45.f * k;                 // 每帧重算，不是累乘
}
```

**不要写成 `ai.speed *= 1.3f`**：每帧都会乘一次，速度会指数爆炸。
必须每帧从基准值重算。

### 16.3 第三阶段的全屏效果

`Game::draw_ui` 的**第一段**（在血条之前画，UI 才不会被压暗）：

```cpp
// 有 Boss 进入第三阶段 → 全屏泛红
bool phase3 = false;
reg_.each<Boss>([&](ecs::Entity, Boss& b) { if (b.phase == 3) phase3 = true; });
if (phase3) {
    const uint32_t a = uint32_t(20 + 10 * std::sin(time_ * 4.f));
    gfx::fill_rect(fb_, {0, 0, fb_.width(), fb_.height()}, (a << 24) | 0x200000u);
}
```

`std::sin` 让红色"呼吸"，比恒定的红光更像"要爆了"。
`a` 的取值 10–30，alpha 只有 4%–12%，够看出氛围，又不会盖住画面。
